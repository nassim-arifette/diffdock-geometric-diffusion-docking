# DiffDock: Geometric Diffusion for Molecular Docking

Course project (MVA, Computer Vision) studying **DiffDock**, a diffusion generative model for molecular docking that operates on the non-Euclidean manifold of ligand poses (translations, rotations, torsion angles).

By Mayeul Ricard and Nassim Arifette.
